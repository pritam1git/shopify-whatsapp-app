# Shopify WhatsApp App

A customizable Shopify WhatsApp widget application that allows store owners to enable direct WhatsApp communication from product pages with product details automatically attached.

This app helps increase customer engagement and improve conversion rates by allowing customers to contact store owners instantly via WhatsApp.

---

## ✨ Features

- WhatsApp widget integration on Shopify product pages
- Direct WhatsApp chat with product information
- Multiple Shopify store support
- Customizable widget appearance
- Change WhatsApp number dynamically
- Widget color customization
- Custom widget title and message
- Product image and details support
- Easy installation and configuration
- Mobile responsive design

---

## 🛠 Tech Stack

- Node.js
- Express.js
- Shopify App API
- JavaScript
- HTML/CSS
- REST APIs
- Embedded App Architecture

---

## 🚀 How It Works

1. Merchant installs the Shopify app.
2. Store owner configures:
   - WhatsApp number
   - Widget color
   - Button text
   - Widget title
3. Widget gets injected into Shopify product pages.
4. Customer clicks the WhatsApp button.
5. Customer is redirected to WhatsApp with:
   - Product name
   - Product URL
   - Product image
   - Custom message
